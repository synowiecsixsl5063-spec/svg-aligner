⚡️ 你遇到的 SVG 排版灾难

LLM 不是排版引擎——它们只是"大概对了"

😵

文字糊成一团

LLM 生成的文本坐标总有 2-5px 的随机漂移。本应左对齐的标题在 x=120、x=122、x=119 随机跳动，多列文字互相侵入。

🤯

方位判断错误

text-anchor 属性混乱导致文本视觉位置与代码坐标不一致，middle/end 锚点让 LLM 彻底迷失方向感。

💥

嵌套变换漂移

三层 <g> 嵌套 transform 后，深层元素的绝对坐标与同级元素差 3-4px，肉眼可见的"差一点"。

🔄

反复调 prompt 耗时

每次让 LLM "再对齐一点"都要重新生成整个 SVG，耗费 API 费用却无法保证精确到像素。

✅ svg-aligner 来了！

三大核心技术，一键终结排版噩梦

1

🎯 5px 极差阈值算法

分组检测元素坐标极差 < 5px → 自动判定为"应该对齐"。1px 级偏移？毫秒级修正。
支持 LEFT / RIGHT / TOP / BOTTOM / CENTER / DISTRIBUTE 八种对齐类型。

2

🔧 逆向 CTM 回写技术

在绝对坐标系中计算偏移量 → 通过逆坐标变换矩阵回写到元素本地属性。
坐标精确如手术刀，无视嵌套 transform 层级，路径元素的 d 属性照样修正。

3

🧹 跨类型去重机制

每个元素最多被一个水平 + 一个垂直修正触及，杜绝级联冲突。
小极差优先保留，大极差自动丢弃——文件干净如新出厂。
